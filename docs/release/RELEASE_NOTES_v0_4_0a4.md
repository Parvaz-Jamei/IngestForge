# IngestForge v0.4.0a6 Release Notes

v0.4.0a6 focuses on provider-contract hardening, config enforcement, typed package readiness, dataset/RAG reliability, safer network behavior, and honest alpha claims.

Highlights:

- Python support metadata: 3.11 to 3.14.
- `mypy` passes and `py.typed` is included.
- OpenAI, DeepSeek, and Gemini payload contracts are tested.
- Brave search adapter is implemented with mocked HTTP tests.
- Dataset writer respects output flags and writes manifest hashes.
- Generic REST destination supports payload templates, response maps, retry, idempotency keys, partial-failure checks, and redacted receipts.
- README feature claims were aligned with implemented alpha behavior.
